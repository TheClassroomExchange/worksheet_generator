# Coding Worksheet Rubric — Grade 1

**Ontario reference:** Math (2020) Strand **C3 Coding**
- **C3.1** — solve problems and create computational representations by writing and executing code involving **sequential events**.
- **C3.2** — read and alter existing code involving sequential events, and describe how changes to the code affect the outcomes.

**Concept scope (G1):** block-based (ScratchJr/Scratch) + unplugged. **Sequential
events only** — order matters, one actor, start→action chain. Light reading
(short, decodable words + symbols). Debugging = re-order a 3–5 block sequence.
**No concurrency, no loops, no variables.**

## Scoring model
5 criteria, each **L1–L4 (1–4 pts)** → **/20**. Grader walks each checklist
top-down, stops at the highest fully-met level. **Pass = total ≥ 15/20 AND
Criterion 2 ≥ L3 (hard gate).**

### C1 — Ontario C3 Alignment
- **L1:** Coding-ish activity but no C3 expectation cited or addressed.
- **L2:** Touches C3.1 *or* C3.2 but the task doesn't clearly require it.
- **L3:** Task plainly exercises C3.1 (write/run a sequence) **or** C3.2 (alter & describe); teacher guide cites the exact code.
- **L4:** All of L3 **and** covers *both* writing a sequence and altering/predicting its effect.

### C2 — Coding-Concept Correctness *(HARD GATE — ≥ L3)*
- **L1:** The block sequence wouldn't produce the stated result.
- **L2:** Produces the result but with a redundant/ambiguous step.
- **L3:** Every modeled/solution sequence is correct and minimal; internal `solution_NN` trace matches the intended output.
- **L4:** All of L3 **and** the answer key explains *why* the order works and what breaks if reordered.

### C3 — Grade-Appropriate Pedagogy & Cognitive Load
- **L1:** Introduces loops/concurrency or >6 blocks, or dense reading — beyond G1.
- **L2:** Sequential but one passage exceeds early-reader decoding or step budget (>6).
- **L3:** Sequential only; ≤6 blocks; short decodable instructions paired with icons; one objective.
- **L4:** All of L3 **and** I-do/we-do/you-do scaffold + a low-floor entry and a small challenge.

### C4 — Clarity, Structure & Mascot/Visual Integration
- **L1:** Unclear task or blocks shown inaccurately (don't resemble real Scratch blocks).
- **L2:** Clear but example→practice progression is missing.
- **L3:** Worked example → guided practice → independent try; mascot is the on-screen sprite/actor; image `keywords` match instruction text.
- **L4:** All of L3 **and** a "predict before you run" prompt; image/text alignment gate clean.

### C5 — Teacher Guide Completeness
- **L1:** Objective only.
- **L2:** Objective + steps, missing answer key or the C3 citation.
- **L3:** Objective, materials, facilitation steps, **answer key**, C3 expectation cited, common-error note.
- **L4:** All of L3 **and** differentiation (simplify + extend) and a 1-line success indicator.

## Remediation mapping
- C1/C2 fail → regen `worksheet_NN` + `solution_NN`.
- C3/C4 fail → regen `worksheet_NN`.
- C5 fail → regen `teacher_guide_NN`.
