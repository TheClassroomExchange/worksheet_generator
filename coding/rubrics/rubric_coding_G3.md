# Coding Worksheet Rubric — Grade 3

**Ontario reference:** Math (2020) Strand **C3 Coding**
- **C3.1** — write and execute code involving **sequential, concurrent, and repeating events**.
- **C3.2** — read and alter existing code involving sequential, concurrent, and repeating events, and describe how changes affect outcomes.

**Concept scope (G3) — three subjects:**
- **Block Coding (Scratch):** sequential + concurrent + **repeating events (loops)**; simple conditionals preview.
- **Intro Python Turtle:** text bridge — `forward/left/right`, `for` loops, simple shapes. First exposure to typed code.
- **Debugging:** read/alter/fix given code (block or Turtle); predict-then-correct.

Reading: short paragraphs OK. This is the only K–3 grade with **typed code** and
**loops**, so the rubric adds a loop-correctness emphasis.

## Scoring model
5 criteria, each **L1–L4 (1–4 pts)** → **/20**. Grader walks each checklist
top-down, stops at the highest fully-met level. **Pass = total ≥ 15/20 AND
Criterion 2 ≥ L3 (hard gate).** For **Intro Python Turtle** sheets the
`solution_NN` code MUST execute clean in the run-gate to earn C2 ≥ L3.

### C1 — Ontario C3 Alignment
- **L1:** No C3 expectation cited or addressed.
- **L2:** Addresses only sequential/concurrent (G2 level) — under-reaches G3 (no repetition).
- **L3:** Task exercises **repeating events / loops** per C3.1 or C3.2 (subject-appropriate); teacher guide cites the code.
- **L4:** All of L3 **and** covers both writing a loop and altering it to predict/justify the changed outcome.

### C2 — Coding-Concept Correctness *(HARD GATE — ≥ L3)*
- **L1:** Loop/Turtle code is wrong or wouldn't run.
- **L2:** Runs but the loop is unrolled/faked (no genuine repetition) or off-by-one.
- **L3:** Loop logic correct & genuinely repeats; **Turtle `solution_NN` executes clean** (run-gate); trace matches intended figure/output.
- **L4:** All of L3 **and** answer key explains the loop count/structure and what changing the count does.

### C3 — Grade-Appropriate Pedagogy & Cognitive Load
- **L1:** Introduces functions/variables/nested loops or dense syntax — beyond G3.
- **L2:** Loop present but cognitive/syntax load (e.g. unexplained Python punctuation) is unmanaged.
- **L3:** One new idea (loop OR a single Turtle command set); typed code kept short with a copy-this model; one objective.
- **L4:** All of L3 **and** block→text bridge made explicit (show the block, then its Turtle equivalent) + low-floor + challenge.

### C4 — Clarity, Structure & Mascot/Visual Integration
- **L1:** Code shown inaccurately or task unclear.
- **L2:** Clear but no worked example before the typed/loop task.
- **L3:** Worked example → guided → independent; code blocks legible (monospace, correct indentation); **mascot** frames the task / appears as the Turtle; image `keywords` match text.
- **L4:** All of L3 **and** a "predict the drawing/output, then run" prompt; image/text alignment gate clean.

### C5 — Teacher Guide Completeness
- **L1:** Objective only.
- **L2:** Objective + steps, missing answer key or C3 citation.
- **L3:** Objective, materials, facilitation steps, **answer key (with runnable code)**, C3 expectation cited, common-error note (off-by-one, missing indentation).
- **L4:** All of L3 **and** differentiation (simplify to blocks / extend to a 2nd loop) and a success indicator.

## Remediation mapping
- C1/C2 fail → regen `worksheet_NN` + `solution_NN` (re-run the code gate).
- C3/C4 fail → regen `worksheet_NN`.
- C5 fail → regen `teacher_guide_NN`.
