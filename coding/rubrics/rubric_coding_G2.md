# Coding Worksheet Rubric — Grade 2

**Ontario reference:** Math (2020) Strand **C3 Coding**
- **C3.1** — write and execute code involving **sequential and concurrent events**.
- **C3.2** — read and alter existing code involving sequential and concurrent events, and describe how changes affect outcomes.

**Concept scope (G2):** block-based (Scratch). **Sequential + concurrent events** —
two or more scripts/sprites acting at once, `when green flag` parallel starts,
simple events/broadcasts. Reading: short sentences. Debugging = find which of two
parallel scripts is wrong. **Loops/variables still out of scope (preview only).**

## Scoring model
5 criteria, each **L1–L4 (1–4 pts)** → **/20**. Grader walks each checklist
top-down, stops at the highest fully-met level. **Pass = total ≥ 15/20 AND
Criterion 2 ≥ L3 (hard gate).**

### C1 — Ontario C3 Alignment
- **L1:** No C3 expectation cited or addressed.
- **L2:** Addresses only sequential events (G1 level) — under-reaches G2.
- **L3:** Task exercises **concurrent** events (≥2 scripts/sprites at once) per C3.1 or C3.2; teacher guide cites the code.
- **L4:** All of L3 **and** covers both writing concurrent code and altering/predicting how the parallel scripts interact.

### C2 — Coding-Concept Correctness *(HARD GATE — ≥ L3)*
- **L1:** The concurrent scripts wouldn't produce the stated combined behavior.
- **L2:** Works but the two scripts are effectively sequential (no real concurrency demonstrated).
- **L3:** Concurrency is genuine and correct; internal `solution_NN` trace matches the combined outcome.
- **L4:** All of L3 **and** answer key explains the interaction/timing of the parallel scripts.

### C3 — Grade-Appropriate Pedagogy & Cognitive Load
- **L1:** Jumps to loops/variables or >8 blocks across scripts — beyond G2.
- **L2:** Concurrency present but cognitive load (too many simultaneous things) is unmanaged.
- **L3:** Two parallel ideas max; ≤8 total blocks; sentence-level instructions with icons; one objective.
- **L4:** All of L3 **and** scaffold that introduces the 2nd script only after the 1st is understood.

### C4 — Clarity, Structure & Mascot/Visual Integration
- **L1:** Blocks/scripts shown inaccurately or task unclear.
- **L2:** Clear but doesn't visually distinguish the two concurrent scripts/sprites.
- **L3:** Two scripts clearly separated; worked example → guided → independent; **two mascots** as the two sprites; image `keywords` match text.
- **L4:** All of L3 **and** a "predict what happens when both start" prompt; image/text alignment gate clean.

### C5 — Teacher Guide Completeness
- **L1:** Objective only.
- **L2:** Objective + steps, missing answer key or C3 citation.
- **L3:** Objective, materials, facilitation steps, **answer key**, C3 expectation cited, common-error note (esp. mistaking sequential for concurrent).
- **L4:** All of L3 **and** differentiation (simplify + extend) and a success indicator.

## Remediation mapping
- C1/C2 fail → regen `worksheet_NN` + `solution_NN`.
- C3/C4 fail → regen `worksheet_NN`.
- C5 fail → regen `teacher_guide_NN`.
